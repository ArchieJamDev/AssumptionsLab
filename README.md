# AssumptionsLab

> **A Jamovi module for statistical assumptions assessment and evidence-based methodological decision support.**

AssumptionsLab is an open-source Jamovi module designed to help researchers, students, and practitioners evaluate the statistical assumptions required for common analytical techniques. Unlike conventional statistical software that simply computes diagnostic tests, AssumptionsLab integrates statistical evaluation with methodological guidance, interpretation, and educational support.

The project follows an evidence-based approach to statistical decision-making, transforming assumption assessment into a structured methodological workflow rather than an isolated set of statistical tests.

---

# Why AssumptionsLab?

Statistical assumptions are frequently treated as a checklist performed immediately before running an analysis. However, assumption assessment is a critical component of the entire research process, influencing model selection, result validity, and interpretation.

AssumptionsLab was created to bridge the gap between statistical computation and methodological reasoning by providing:

- Evidence-based methodological guidance.
- Comprehensive interpretation of statistical diagnostics.
- Educational explanations integrated within the software.
- Recommendations supported by scientific literature.
- A methodological reference library directly accessible from every analysis.

Rather than asking users to memorize statistical rules, AssumptionsLab helps them understand **why assumptions matter and how they influence analytical decisions**.

# Methodological Philosophy

AssumptionsLab is built around five fundamental principles.

1. Statistical software should support—not replace—methodological decision making.

2. Every recommendation should be grounded in scientific evidence.

3. Statistical results require meaningful interpretation rather than isolated numerical output.

4. Learning is an integral objective of the software.

5. Methodological knowledge should be available exactly when it is needed.

# Project Architecture

The project consists of several complementary components.

- **Jamovi Module** — Statistical analyses and graphical diagnostics.
- **Methodological Library** — Scientific explanations of statistical concepts.
- **Documentation System** — Technical and user documentation.
- **Evidence Base** — References supporting implemented recommendations.
- **Editorial Framework** — Consistent scientific communication across the project.
